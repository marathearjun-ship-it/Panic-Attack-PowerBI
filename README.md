# Panic Attack Data Analysis using Power BI and Snowflake

## 📊 Project Overview

This project analyzes panic attack-related data using Microsoft Power BI and Snowflake.

The objective is to explore patterns related to panic attacks, symptoms, triggers, sleep, age groups, and panic attack frequency through interactive dashboards.

## 🛠️ Technologies Used

- Microsoft Power BI
- Snowflake
- SQL
- Power BI Desktop
- DAX
- Power Query

## ❄️ Data Platform

The dataset is stored in Snowflake and connected to Power BI for analysis and visualization.

## 📈 Power BI Report

The report contains the following analysis pages:

### 1. Panic Attacks
Provides an overview of panic attack-related metrics and trends.

### 2. Patients by Symptoms
Analyzes the number of patients across different symptoms.

### 3. Other Requirement
Provides additional analysis using interactive filters and visualizations.

### 4. Age Group Analysis
Analyzes sleep hours, panic scores, and panic attack frequency across different age groups and trigger reasons.

## 🔍 Key Analysis Areas

- Panic attack frequency
- Panic score
- Trigger reasons
- Sleep hours
- Symptoms
- Age group analysis
- Patient-level analysis
